Сервис  для  отправки  запросов  в  Гену  посредством  http запросов .
Как  получить  токен  авторизации
Для  этого  есть  метод  createUserToken - токен  может  создать  как  сам  пользователь  для
самого  себя
Meteor.call('api.tokens.createUserToken', {}, (err, res) => {
    console.log(res)
})
так  и  суперадмин  для  пользователя  ( в  интерфейсе  кнопка  пока  есть  только  для
суперадмина  - находится  на  странице  пользователя ). Сгенерированный  токен  необходимо
сохранить  и  обезопасить  от  попадания  в  руки  злоумышленников , т . к . с  помощью  токена
можно  выполнить  любой  метод , который  доступен  данному  пользователю . Все  запросы
будут  проходить  из - под  его  имени . При  повторной  генерации  токена  предыдущий
станет  недоступен !
