# GENA API Notes

Источник: `GENA-GENA API-260526-090129.pdf`.

## Как работает API

- Base URL для прода: `https://portal.itgen.io`.
- Endpoint: `POST /api/gena`.
- Заголовки:
  - `Content-Type: application/json;charset=utf-8`
  - `authorization: <user token>`
- Тело запроса:

```json
{
  "methodName": "api.skills.getSkills",
  "params": []
}
```

В ответ приходит объект вида:

```json
{
  "status": "ok",
  "result": {}
}
```

Если метод вызван неправильно, API может вернуть HTTP 400 и:

```json
{
  "status": "error",
  "error": "..."
}
```

## Важное про токен

Токен действует от имени пользователя и позволяет выполнять методы, доступные этому пользователю. Его нельзя хранить в репозитории, Excel-файле, README или фронтенде веб-страницы.

Для будущей веб-страницы токен должен жить только на серверной стороне.

## Найденные методы для направлений

Из клиентского бандла портала и пробных read-only запросов:

- `api.skills.getSkills` - возвращает направления, сгруппированные по `skillId`, с языковыми версиями (`ru`, `en`, `es`, иногда `de`, `fr`, `he`, `ukr`).
- `api.skills.getSkillsList` - требует параметр `{}`; возвращает направления по группам.
- `api.skills.getAllSkillsIds` - возвращает список ID направлений.
- `api.skills.getSkillsGroups` - возвращает группы направлений и порядок.
- `api.skills.getSkillsOrder` - возвращает порядок направлений.

## Поля, полезные для базы знаний

В `api.skills.getSkills` / `api.skills.getSkillsList` есть:

- `title` - название направления.
- `desc` - краткое описание.
- `minAge` / `maxAge` - возрастные ограничения, если заполнены.
- `visibility` - видимость направления (`visible`, `onlyAdmin`, `onlyTrial`, `hidden`, `invisibly` и т.п.).
- `lessonsFormats` - доступные форматы занятия в кодах платформы.
- `operationSystems` - поддерживаемые ОС.
- `tabletSystems` - поддерживаемые планшетные ОС.
- `note` - важные заметки по направлению: требования, установка, пробное, чему учим, особенности.
- `downloadLink` - ссылка на материал/описание направления, если есть.
- `tildaLinkForParent` - публичная страница для родителя, если есть.
- `requiredSkillId` - prerequisite/предыдущее направление, если есть.
- `groupId` - группа направления.

## Что API закрывает хорошо

- Есть ли направление.
- Минимальный/максимальный возраст.
- Языковые версии описания/материалов направления.
- Видимость/доступность направления в Гене.
- Описание направления и часть содержания.
- Устройства и ОС, если заполнены.
- Установщик/подготовка, если это описано в `note`.
- Подбор направления по интересу через `title`, `desc`, группу, возраст и prerequisites.

## Что найденные методы не закрывают полностью

- Кто заведующий направлением.
- Готовность конкретных тренеров вести на нужном языке.
- Готовность тренеров работать с РАС/другими особенностями.
- Актуальность AI-сервисов по странам, РФ/РБ, VPN.
- Консультации по поступлению/вузам.

Для этих тем нужен отдельный источник: таблица владельцев, CRM/таблица тренеров, регламент инклюзии, таблица актуальности сервисов, справочник продаж.
