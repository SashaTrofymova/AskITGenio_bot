## Принцип для бота

Бот должен отвечать только по подтвержденным источникам. Если в базе нет ответа или данные требуют проверки, бот должен явно сказать, что подтвержденного ответа нет, и подсказать маршрут эскалации.

## Веб-часть

Папка `web/` зарезервирована под будущую страницу бота. Рекомендуемая минимальная структура:

- `web/src/` - компоненты, логика чата, работа с API.
- `web/public/` - статические файлы.
- `web/README.md` - инструкции по запуску веб-части, когда она появится.
