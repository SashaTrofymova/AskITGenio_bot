# Workbook Scripts

Скрипты для работы с базой знаний.

- `build_workbook.mjs` - собирает исходный шаблон в `../../knowledge_base/templates/`.
- `verify_workbook.mjs` - проверяет главный файл `../../knowledge_base/AskITGenio_knowledge_base.xlsx`.
- `export_csv_from_xlsx.mjs` - экспортирует основные листы из главного файла в `../../knowledge_base/exports/`.
- `test_import.mjs` - маленькая техническая проверка импорта библиотеки.

Важно: текущий главный файл базы знаний уже лежит в `../../knowledge_base/AskITGenio_knowledge_base.xlsx`.
